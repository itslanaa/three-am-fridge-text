One line a smart fridge would text its owner at 3am.

> It's 3am. The ice cream is gone, the milk expired yesterday, and I can see you. Go back to bed.

`main.ts` writes the line to `entry.txt` in `MAKEFUN_OUTPUT_DIR`.
